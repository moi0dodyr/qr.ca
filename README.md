# QR.CA — prototype

Clickable front-end prototype of [QR.CA](https://qr.ca), a Canadian dynamic QR code generator. Built with React 19, TypeScript, Vite and Tailwind CSS v4.

```bash
npm install
npm run dev     # local dev server
npm run lint    # oxlint
npm run build   # typecheck + production build
```

- Requirements, tasks and the work pipeline: [`docs/srs/README.md`](docs/srs/README.md)
- Design (Figma, tokens): [`docs/design/README.md`](docs/design/README.md)
- Working rules for Claude Code: [`CLAUDE.md`](CLAUDE.md)

This is a prototype: there is no backend, and server behaviour is mocked.
