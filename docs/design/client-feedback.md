# Client feedback

Feedback from the client (al) on Figma, recorded so it shapes future design and prototype work. Newest first. Client quotes are verbatim; the "What it means for us" lines are our reading.

## Standing principles

These come from the entries below and apply to every screen until the client says otherwise.

1. **Keep copy short.** Don't over-explain in the UI. Wordy copy assumes things about who the user is.
2. **Don't guess the ICP yet.** The ideal customer profile isn't settled. Don't design or write for a specific audience (business size, industry, role).
3. **Reference products for MVP UI: Uniqode and QR Code Generator by Bitly (QRCG).** Use them as the starting point for layout, density and feature depth. Keep the UI simple; don't overcomplicate.
4. **Don't lean on "Canadian" in copy.** The `.ca` domain already says it. Don't put "Canadian" in CTAs or marketing copy.
5. **One clear CTA per screen.** Pick the main action and make it obvious; don't repeat secondary info that's shown elsewhere.
