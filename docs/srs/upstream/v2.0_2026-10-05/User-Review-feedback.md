## [User] - Review feedback - read private feedback and ratings
| User story | As a business owner I want to read what unhappy customers tell me privately so that I can fix problems |
| Role | User |
| Platform | Web (desktop and mobile) + email |
| App map | Not drawn in Figma |
| UI | TBD |
Overview
A review code sends scanners to the business's Google reviews, optionally after a short rating step where they can also leave private feedback. This page is where the owner reads that feedback.
Acceptance criteria
- When a scanner leaves private feedback, then the owner gets an email and the feedback appears on the code's analytics page.
- The code's analytics page also shows the rating distribution (1–5) next to the scans.
