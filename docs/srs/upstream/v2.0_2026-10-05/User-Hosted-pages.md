## [User] - Hosted pages - open a links page or a business card
| User story | As someone scanning the code I want the page behind the code to open quickly on my phone so that I get what I came for |
| Role | User (not signed in, scanning a code) |
| Platform | Phone browser |
| App map | Not drawn in Figma |
| UI | TBD |
Acceptance criteria
- A links page shows the owner's logo, colours and the links as buttons.
- A business card shows the contact details with Save to contacts (downloads a contact file).
- The page shows meaningful content quickly on a mid-range Android phone over mobile data (proposed: within 2 seconds).
- The page never shows advertising or third-party content, apart from the owner's own tags (see [User] - Integrations).
- When the owner set a search-engine switch to hidden, then the page is not indexed.
▸ Traceability
  F-22 · F-24 · QR-U-38 · BRL-34 · not drawn (C-4)

## [User] - Hosted pages - open a PDF or a menu
| User story | As someone scanning the code I want the PDF or menu to open directly so that I read it without an app |
| Role | User (not signed in, scanning a code) |
| Platform | Phone browser |
| App map | Not drawn in Figma |
| UI | TBD |
Acceptance criteria
- The file opens directly on the phone with a small QR.CA footer; zoom and scroll work.
- The scanner can download the file.
- When the owner replaced the file, then the scanner sees the new one.
▸ Traceability
  F-22 · F-03 · QR-U-09, QR-U-20 · DS-04, DS-06

## [User] - Hosted pages - read the page in English or French
| User story | As a French-speaking person scanning the code I want the page in French so that I understand it |
| Role | User (not signed in, scanning a code) |
| Platform | Phone browser |
| App map | — |
| UI | TBD |
Acceptance criteria
- When the phone's language is French, then the page opens in French; otherwise in English.
- A visible EN / FR switch changes the language for the rest of the visit.
- When the owner filled only one language, then that language is shown to everyone.
▸ Traceability
  F-12 · QR-U-18 · BRL-16, BRL-21
