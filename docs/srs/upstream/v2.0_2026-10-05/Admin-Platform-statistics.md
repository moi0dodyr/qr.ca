Acceptance criteria
- For a chosen period: sign-ups, trials, conversions to paid, cancellations, codes created by type, scans.
- An industry breakdown: the destinations of website codes are grouped into industries with an AI model and shown as shares.
- Only totals; no scanner is identified.
