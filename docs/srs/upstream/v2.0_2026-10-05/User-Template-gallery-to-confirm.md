## [User] - Template gallery - browse templates and open one in the generator
| User story | As a visitor I want to see ready-made designs and start from one so that my first code looks good without effort |
| Role | User (not signed in) |
| Platform | Web (desktop and mobile) |
| App map | Not drawn in Figma |
| UI | TBD |
Overview
A public page on the marketing site, linked from the footer, that lists the starter templates. Picking one opens the home-page generator with that template applied. A competitor (EZQR) uses this as an entry point from search. Not in the V1 baseline yet.
Acceptance criteria
- When the visitor opens the gallery, then the starter templates are shown as previews.
- When the visitor picks a template, then the home-page generator opens with it applied.
- The page is indexable by search engines.
Not decided yet
- In V1 or later: with the client (the client postpones SEO content before the MVP).
- Which templates (the same starter set as in code creation): design.
