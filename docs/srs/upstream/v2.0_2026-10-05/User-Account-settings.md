## [User] - Account settings - delete the account
| User story | As a user I want to delete my account and data so that I can leave completely |
| Role | User |
| Platform | Web (desktop and mobile) |
| App map | Figma, Account settings (Manage account) |
| UI | TBD |
Acceptance criteria
- Delete account opens a window explaining that the data cannot be restored and what happens to printed codes.
- The user types their full name and presses Confirm.
- Then any plan is cancelled, personal data is deleted, and a final page offers Go to home page and Contact support.
- Anyone who scans a code of the deleted account sees a "no longer available" page.
